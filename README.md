# Manisha Photo Studio & Colour Lab

Official website for **Manisha Photo Studio & Colour Lab**, a photography studio and colour lab based in Bodhan, Nizamabad, Telangana.

The website provides information about the studio, photography services, selected works, business timings, booking process, FAQs, and contact details.

## 🌐 Live Website

**Live Demo:** https://manisha-photo-studio.netlify.app

## 📂 GitHub Repository

**Repository:** https://github.com/shivamani90141-byte/manisha-photo-studio

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/shivamani90141-byte/manisha-photo-studio.git
```

Navigate to the project:

```bash
cd manisha-photo-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

---

## 📦 Deployment

The project is deployed using **Netlify** and connected directly to the GitHub repository.

Every new commit pushed to the `main` branch automatically triggers a new production deployment.

```text
Local Development
       ↓
      Git
       ↓
    GitHub
       ↓
    Netlify
       ↓
 Live Website
```
